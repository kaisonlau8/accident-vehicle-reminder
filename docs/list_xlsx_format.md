# list.xlsx 格式说明

此文件由飞书「参与考核特约店清单」同步生成，包含真实手机号和 open_id，**不应提交到 GitHub**。

## 列

| 列名 | 说明 |
|------|------|
| 序号 | 行号 |
| 门店编码 | 店代码 |
| 区域 | 飞书联系人区域，仅用于匹配区域督导，不覆盖 DMS 大区 |
| 门店名称 | 店名称 |
| 督导姓名 | 飞书联系人姓名 |
| 督导飞书电话号 | 督导手机号，可空 |
| 督导open_id | 优先用于发消息 |
| 售后负责人 / 售后电话 / 售后open_id | 首个非空售后业务负责人（主负责人） |
| 门店省 / 门店市 / 门店区 | 只缓存，不参与路由 |
| 售后负责人2 / 售后电话2 / 售后open_id2 | 2 号售后业务负责人 |
| 售后负责人3 / 售后电话3 / 售后open_id3 | 3 号售后业务负责人 |
| 售后负责人4 / 售后电话4 / 售后open_id4 | 4 号售后业务负责人 |

飞书字段「门店售后业务负责人 N」「售后业务负责人手机号 N」按编号配对，兼容无编号旧字段（视为 1 号）。所有槽位都为空的门店，超期告警和门店报表会跳过。

报告中的区域只取 DMS 大区并归一化（去空白、去掉末尾一个「区」，如「华中1区」→「华中1」）；飞书区域只用于查找该区域督导。

全国收件人不在 `list.xlsx` 中维护，请在 Web 控制台的「门店联系人」页面新增或删除。
