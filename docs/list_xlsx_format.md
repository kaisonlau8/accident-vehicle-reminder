# list.xlsx 格式说明

此文件由飞书「参与考核特约店清单」同步生成，包含真实手机号和 open_id，**不应提交到 GitHub**。

## 列

| 列名 | 说明 |
|------|------|
| 序号 | 行号 |
| 门店编码 | 店代码 |
| 区域 | 管理区域，如华东、华中 1 |
| 门店名称 | 店名称 |
| 督导姓名 | 飞书联系人姓名 |
| 督导飞书电话号 | 督导手机号，可空 |
| 督导open_id | 优先用于发消息 |
| 售后负责人 | 门店售后业务负责人 |
| 售后电话 | 数字字段会去掉小数 |
| 售后open_id | 优先用于发消息 |
| 门店省 / 门店市 / 门店区 | 只缓存，不参与路由 |

没有售后负责人联系人、也没有售后电话的门店，超期告警和门店报表会跳过。

全国收件人不在 `list.xlsx` 中维护，请在 Web 控制台的「门店联系人」页面新增或删除。
